# 排序代码提交文件夹

在网页完成排序代码，当前测试数组验证通过后，下载源文件并手动放到本目录。可更换数组进一步验证负数、重复值、已排序和逆序等情况。

文件使用 `班级_姓名.扩展名` 命名，班级和姓名之间保留一个下划线：

- Python：`电子2602_任天灵.py`
- C：`电子2602_任天灵.c`
- C++：`电子2602_任天灵.cpp`

每人选择一种语言，只提交自己最终通过验证的源文件。修改代码后请重新在网页验证，下载最新版本。

默认使用 Python，无需另外安装编译器。先双击项目根目录的 `start.bat`，浏览器打开后即可作答。

将源文件与自己的 `members/NN.html` 一起提交到个人分支，向 `调整测试` 分支发起 PR，等待审核。无需提交草稿、截图、编译出的可执行文件或临时文件。

成员对应关系见 [分工表](../members/README.md)，完整流程见 [项目说明](../README.md)。
