# 成员介绍开发区

每位同学负责一个 HTML 文件。姓名与班级已分配，介绍文字、技能或兴趣、学习目标仍需本人完成。

自我介绍只使用 HTML 和 CSS，建议用 VS Code 编辑，保存为 UTF-8 并保留 `.html` 扩展名。不需要 Node、npm 或前端依赖；在 VS Code 选择“终端 → 运行任务 → 启动项目（Windows）”。Windows 文件资源管理器中也可以双击项目根目录的 `start.bat`。

## 开发步骤

1. 先按 [学生零基础操作指南](../STUDENT_GUIDE.md) Fork 课程公开仓库，再用 VS Code 克隆自己的 Fork、配置提交身份、创建个人分支并启动项目。
2. 在上表找到自己对应的文件，使用 VS Code 等编辑器打开。
3. 将“待完成”和三个标签替换为自己的介绍内容。可以更改当前文件的颜色变量，也可以在该文件的 `<head>` 中添加 `<style>` 调整布局。
4. 保存后刷新网页，在“成员介绍”中检查自己的卡片。默认展示区域约宽 300–450 像素、高 260 像素，介绍尽量简短。
5. 在 VS Code 只暂存、提交自己的 HTML 和排序题代码，发布个人分支到自己的 Fork，再向课程仓库的 `main` 创建 PR。看到 PR 编号和 Open 状态即完成提交，老师负责审核合并。

只修改自己的 HTML 文件即可完成这部分考核。公共样式 `card.css` 由项目统一维护；个人设计写在自己的 HTML 中，方便多人同时开发。
